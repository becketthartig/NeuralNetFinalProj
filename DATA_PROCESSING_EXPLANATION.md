# How to Achieve daily_features.csv and daily_features_normalized.py
### Step 1
Run FIRST.py in the data folder on elonmusk.csv to achieve tweettimes.csv
### Step 2
Run SECOND.py in the data folder on tweettimes.csv to achieve daily_features.csv
### Step 3
Run the normalizer in the data folder on daily_features.csv to achieve daily_features_normalized.csv
